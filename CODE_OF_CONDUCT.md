# Code of Conduct

## Our pledge

We want NyxMail to be a welcoming project for everyone, regardless of experience,
identity, background or employer. We pledge to make participation harassment-free
for all contributors and users.

## Expected behaviour

- Be respectful and assume good faith.
- Give actionable technical feedback, not personal attacks.
- Welcome questions and different levels of experience.
- Respect privacy: never post another person's email, logs, keys or mailbox data.
- Accept maintainers' decisions about scope and security trade-offs.

## Unacceptable behaviour

- Harassment, discrimination, threats or sexualised language.
- Publishing private information without permission.
- Deliberately disruptive behaviour, spam or bad-faith security reports.
- Encouraging others to break the law or compromise deployed systems.

## Enforcement

Report conduct issues privately to the maintainers through the repository's
GitHub profile or a private security advisory if the report is sensitive.
Maintainers may remove comments, close issues, or temporarily or permanently ban
contributors for behaviour they consider inappropriate.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
